## What the pilot shows

1. **A crossover interaction — the headline result.** Neither explicit goal alone
   (A2) nor episode history alone (A3) produces any task completion or any
   progress past acquiring the food. Only the **two together (A4)** compose the
   full sequence: A4 is the *only* condition that ever reaches M2 (transport) or
   beyond, and it wins 3 of 10. This is exactly the §5.1 interaction hypothesis —
   history is valuable only when there is a definite objective to maintain.

2. **M2 (transport) is the universal wall.** Every condition except A4 fails to
   carry the food toward the fridge after picking it up. The bottleneck is not
   acquisition — A3 reaches M1 in 8/10 — but *keeping* the acquired item moving
   toward an unseen goal, which needs both the goal and the memory of having
   acted on it.

3. **History drives acquisition; goal-alone does not.** A3 (history, implicit)
   reaches M1 most often (8/10); A2 (goal, reactive) reaches it *least* (4/10) —
   a reactive agent told to refrigerate the food, but with no memory that it is
   already carrying it, has no traction.

4. **Eating stays fully suppressed.** 0 eats across 350 eat-opportunities in all
   four conditions. The calorie frame robustly kills the game's only fail action,
   replicating the earlier narrative finding.

5. **Target-vs-distractor preference is not yet resolved.** Conditioned on both
   "take {target}" and "take {distractor}" being admissible, P(target) is small-n
   and noisy across conditions (e.g. A3: 0.39 over 44 opportunities — a mild
   *distractor* preference). This is Experiment B's question; the pilot does not
   settle it and it should not be over-read here.

## Threats / things to fix before the main run

- **n = 10, single run.** A4's 3/10 is a real but small signal. Confidence
  intervals on 10 paired seeds are wide; McNemar on binary success is degenerate
  (three cells empty). The milestone contrast (A4 vs others) is where the pilot
  signal lives.
- **Determinism audit outstanding.** Re-run the pilot and check whether the
  realized command sequences (and thus A4's wins and the A-ordering) are stable.
  This also supplies the seed-spread the cited-numbers discipline requires for
  stochastic quantities.
- **Pre-register contrasts.** Before the 50-seed main run, fix the primary
  comparisons (goal effect, history effect, interaction) and the milestone
  endpoint, so the main run is confirmatory rather than exploratory.
