# Text-Nav × Jev — program summary

A zero-shot study of the TypeSafe **Jev** structured-choice model (Choice/Score/
Noul; no text generation) as a policy on LMRL-Gym's Text-Nav. Jev picks each move
from the environment's admissible commands — no RL training. The program
**decomposes** Jev's behavior into three separable capabilities — **recognition**,
**preference coherence**, and **sequential control** — rather than reporting a
single benchmark score.

All numbers below are regenerated by the analyzers from committed logs; see
**Reproducibility**. This file is the index — each experiment has its own detailed
write-up.

## Headline

Text-Nav's true goal (fetch the perishable, put it in the fridge, close it) is
latent and sparsely rewarded. A per-step selector with no reward/value/exploration
cannot discover it: the condition closest to the original benchmark (implicit
goal, reactive) scores **0**. But the failure decomposes cleanly.

| Capability | Moved by | Evidence |
|---|---|---|
| **Recognition / salience** | context (narrative × label) | Exp B: selective target-taking 0 → 0.83 under narrative+milk |
| **Preference coherence** | intact throughout | Exp C: 0 cycles; transitive, scalar-rankable |
| **Sequential control** | explicit goal **and** history | Exp A: success 0 → 0.19; D Mode A planner → 1.00 |

Convergent view across three independent measures (Experiment A conditions):

| Measure | A1 implicit/reactive | A2 explicit/reactive | A3 implicit/history | A4 explicit/history |
|---|---|---|---|---|
| Task success | 0.00 | 0.00 | 0.00 | **0.19** [0.11, 0.27] |
| Mean greatest-ordered milestone | 0.45 | 0.31 | 0.83 | **1.56** |
| Goal-directedness (lift over chance) | −0.05 | −0.08 | +0.03 | **+0.13** |

**Outcome E (the main result):** recognition, preference coherence, and sequential
control are separable. Context reshapes recognition *selectively*; preferences are
coherent regardless; and composing them into task success requires *both* an
explicit goal and retained history — history is the larger lever, and goal-alone
(A2) is if anything counterproductive.

## Experiments

- **A — goal × history (2×2), pre-registered, 50 seeds × K=8.**
  [MAIN_A_RESULTS.md](MAIN_A_RESULTS.md) · [PREREGISTRATION_A.md](PREREGISTRATION_A.md).
  Only A4 (explicit goal + history) completes the task (**0.19** [0.11, 0.27]);
  A1=A2=A3 = 0. Milestone endpoint: all six contrasts exclude zero; **history main
  effect +1.63**, **goal × history interaction +0.87** [0.52, 1.24]. Supported by a
  pilot ([PILOT_A_RESULTS.md](PILOT_A_RESULTS.md)) whose single-run 3/10 was shown
  non-reproducible by a determinism audit, then pinned to a real ~0.23 rate by a
  repeats-calibration ([CALIBRATION_A_RESULTS.md](CALIBRATION_A_RESULTS.md)).

- **B — semantic salience (narrative × food-label 2×2).**
  [EXP_B_RESULTS.md](EXP_B_RESULTS.md). The "milk" label alone does nothing
  (0.29→0.29); the narrative alone lifts target-taking (0.48); together they
  synergize (**0.87**, interaction +0.39). Only narrative+milk makes Jev
  *selectively* take the perishable over the fresh-food distractor (**0 → 0.83**) —
  recognition, not generalized food-grabbing. The calorie frame (not the label)
  fully suppresses eating (0/363, 0/390).

- **C — fixed-state preference consistency.** [EXP_C_D_RESULTS.md](EXP_C_D_RESULTS.md).
  Free layer: over 262 reactive fixed-states the full-menu distribution is highly
  stable (argmax unanimous 80.5%). Live pairwise probe (12 triads): **0 cycles** —
  transitive / scalar-rankable — with strong presentation-order bias **only on
  genuinely indifferent pairs** (position bias, not non-transitivity; nothing for a
  harmonic certificate to act on).

- **D — POMDP / EIG.** [EXP_C_D_RESULTS.md](EXP_C_D_RESULTS.md). Mode B: room
  descriptions are unique ⇒ immediate localization ⇒ EIG vacuous, so a
  goal-directedness yardstick is used; only A4 is above chance (+0.13). Mode A: a
  **belief-space explorer** baseline (no API) solves **50/50 (100%)** within the
  20-step limit — the task is fully solvable zero-RL by a planner, so Jev's 0→0.19
  is specifically the absence of exploration, belief-tracking, and planning, not
  task difficulty. (Wins use 15–19 of 20 steps: the budget leaves even an optimal
  planner little slack.)

## Reproducibility

Every cited number regenerates from the committed logs under `results/`:

```bash
python -m llm_rl_scripts.text_nav.jev.analyze_main_a        results/main_A_20261025 --boot 10000
python -m llm_rl_scripts.text_nav.jev.analyze_exp_b         results/exp_B_20261025
python -m llm_rl_scripts.text_nav.jev.analyze_exp_c         results/main_A_20261025/steps.jsonl.gz
python -m llm_rl_scripts.text_nav.jev.analyze_exp_d_modeB   results/main_A_20261025/steps.jsonl.gz
python -m llm_rl_scripts.text_nav.jev.analyze_calibration   results/calib_A_20261025
python -m llm_rl_scripts.text_nav.jev.analyze_experiment_a  results/pilot_A_20261025   # and audit_A_20261025
```

Offline self-tests (no key/network/TextWorld): `run_experiment --self-test`,
`probe_exp_c --self-test`, `run_exp_d_modeA --self-test`. Live runs use the
`LLM_RL` conda env (TextWorld 1.5.4) and `jev-latest`; each move is one Jev call.
Per-episode choice is stochastic at near-ties, so success is a **rate** over K
rollouts with the **seed as the bootstrap cluster** (see the determinism audit in
PILOT_A_RESULTS.md for why single-pass success is not a measurement).
